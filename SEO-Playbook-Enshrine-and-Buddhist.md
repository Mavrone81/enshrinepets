# SEO Playbook — Enshrine Pet & Singapore Buddhist Funeral Services

Two local Singapore death-care sites, same platform (WordPress/Elementor), same structural fixes. This doc covers: (1) a prioritised action checklist, (2) exact title tags + meta descriptions for every page, and (3) a paste-ready brief for Claude Code to build the new page structure.

- Enshrine Pet — https://enshrinepet.com.sg
- Singapore Buddhist Funeral Services — https://singaporebuddhistfuneral.com.sg (Singapore Bereavement Group Pte Ltd)

---

## Part 1 — Prioritised action checklist

Ranked by effort-to-payoff. Do the "Fast wins" first; they drive calls within weeks. "Foundation" is the bigger long-term play.

### Fast wins (start this week)
- [ ] **Set up & verify Google Business Profile (GBP)** for each business. This is the #1 driver of calls in local death-care.
  - Enshrine primary category: *Pet funeral service* (secondary: *Pet cemetery*). Address: 47 Lorong 16 Geylang, Singapore.
  - Buddhist primary category: *Funeral home* (secondary: *Funeral director*).
  - Fill every field: hours (24-hour where true), phone, website, services, 10+ real photos, and a short business description with your main keyword.
- [ ] **Reviews flow.** Ask every family for a Google review afterward (a short link or QR card). Steady trickle > one-time burst. Reply to every review.
- [ ] **Submit the site to Google Search Console** and upload an XML sitemap. This is how you'll measure everything below.
- [ ] **Compress all images** (the columbarium/photo files are large). Faster load = better rankings and fewer drop-offs on mobile.
- [ ] **Write proper title tags + meta descriptions** for every page (see Part 2).

### Foundation (the bigger long-term play)
- [ ] **Split each single-page site into separate, indexable pages** — one focused keyword per page (see Part 3 for the structure and the Claude Code brief).
- [ ] **Bilingual SEO done right.** Make sure the English and Chinese versions each have their own crawlable URL with `hreflang` tags — not just a JavaScript text swap. If Google can't crawl the Chinese version separately, you lose half your search visibility.
- [ ] **Add structured data (schema):** `LocalBusiness`/`FuneralHome`, `Service` per offering, `FAQPage` on FAQ sections, `BreadcrumbList`. Free, and it helps Google understand and surface the business.
- [ ] **Trust signals (E-E-A-T).** Death care is a sensitive, high-trust category. Add a real About page (who runs it, ACRA registration / licenses), transparent package pricing, testimonials, clear NAP (Name-Address-Phone) identical everywhere.
- [ ] **Local citations & links.** List in Singapore business directories with identical NAP. Earn links from natural partners: vets & pet shops (Enshrine); temples, casket suppliers, community groups (Buddhist).
- [ ] **Internal linking.** Once the new pages exist, link them to each other (e.g. cremation page → columbarium page → pricing).

## Part 3 — Page structure & paste-ready Claude Code brief

### Target sitemap

**Enshrine:** Home · Pet Cremation · Pet Columbarium · Pet Sea Scattering · Pet Celebrant & Religious · Pricing · About · Contact

**Buddhist:** Home · Funeral Packages · Rites & Traditions · What To Do First · About · Contact

### Paste-ready brief for Claude Code

```
Restructure this site for SEO. It is currently a single-page site; break it into
separate, individually indexable pages — one focused keyword per page.

First tell me whether this is a static HTML site or WordPress/Elementor, because
the implementation differs:
- Static HTML: create one .html file per page below, with a shared nav/footer.
- WordPress/Elementor: create one Page per item below; reuse the existing section
  templates; set the Yoast/RankMath title + meta for each.

Pages to create (use these exact URL slugs, titles and meta descriptions):

[ paste the relevant site's page list from Part 2 here — slug, <title>, meta ]

For EVERY page:
1. Exactly one <h1> containing the page's primary keyword.
2. Unique <title> (~55 chars) and <meta name="description"> (~155 chars) as given.
3. 500+ words of original, useful content for that service (no duplicate boilerplate
   across pages).
4. A clear call-to-action (call / WhatsApp) and the business NAP in the footer,
   identical on every page.
5. Internal links to 2–3 related pages.

Add structured data (JSON-LD) site-wide:
- LocalBusiness (use FuneralHome type) with name, address, phone, hours, geo.
- Service schema on each service page.
- FAQPage schema on any page with an FAQ section.
- BreadcrumbList on inner pages.

Bilingual (EN / 中文):
- Each language must have its own crawlable URL (e.g. /en/... and /zh/..., or a
  separate subdomain) — NOT a JavaScript-only text swap.
- Add reciprocal <link rel="alternate" hreflang="en"> and hreflang="zh-SG" tags,
  plus hreflang="x-default", in the <head> of every page.

Technical:
- Generate an XML sitemap and reference it in robots.txt.
- Compress/serve images in WebP; lazy-load below-the-fold images.
- Ensure mobile-responsive and fast (target LCP < 2.5s).

Don't change the visual design, colours or fonts — structure and SEO metadata only.
```

> Tip: paste only ONE site's page list into the brief at a time, so Claude Code builds them one site per run.

## Measuring progress
- **Google Search Console** — impressions, clicks, average position per keyword/page.
- **Google Business Profile insights** — calls, direction requests, profile views.
- Track your priority keywords (e.g. "pet cremation singapore", "buddhist funeral services singapore") monthly. Local + GBP results usually move within 4–8 weeks; organic page rankings take 2–4 months to mature.
