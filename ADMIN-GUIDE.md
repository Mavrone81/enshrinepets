# Enshrine 欣奉 — Admin User Guide

A simple guide to editing the website at **enshrinepet.com.sg**.

## 1. Logging in
1. Go to **https://enshrinepet.com.sg/admin**
2. Enter your **username** and **password**.
   - Username: `admin`
   - Password: *(set privately — ask your administrator; change it after first login)*
3. Click **Log in**.

> Sessions last 8 hours, then you'll be asked to log in again.

## 2. The admin panel
After logging in you'll see a top bar with:
- **Edit Content** — change the words and photos on the website.
- **Users** — add logins and change passwords.
- **View Site ↗** — open the live website in a new tab.
- **Log out**.

## 3. Editing text & photos (Edit Content)
1. Click **Edit Content**.
2. The page is split into the same **sections** as the website (Hero, About, Services, Columbarium, Niches, Contact, Footer, etc.).
3. Change any **text field**, then click **Save** for that section. Your change is **live immediately**.
4. To replace a **photo**, use the image field in that section — choose a new image file (JPG/PNG, up to 8 MB) and Save. The site automatically serves a fast WebP version.

### Editing other languages
- The site has **6 languages**: English, 中文, Bahasa Melayu, தமிழ், ไทย, Tiếng Việt.
- Use the **language selector** on the Edit Content page to switch which language you're editing.
- **English is the master.** Other languages only store their translations; any field you leave blank in another language automatically shows the English text.
- Phone, email, address, links and images are shared across all languages — you only set them once (in English).

## 4. Managing logins (Users)
Click **Users** in the top bar.
- **Add a new admin:** under *Add a new user*, enter a username + password → **Add user**. Every user is a full admin.
- **Change a password:** on any user's row, type a new password → **Update**. (Use this to change your own password too.)
- **Remove a user:** click **Delete** on their row. You can't delete the account you're logged in with or the last remaining admin.

## 5. Good to know
- **Changes publish instantly** — there's no separate "publish" step.
- **Your edits are safe across updates** — content you change in the admin is preserved even when the site's code is updated.
- Use a **strong password** (the admin page is public on the internet). A passphrase like `BlueDahlia-Geylang-2026!` is far safer than a short one.
- Lost your password? Another admin can reset it on the Users page. If no one can log in, your developer can reset it on the server.
